# Medium Selection

Choose by physical affinity, not taste.

| Source fact | Candidate process | Native verbs |
|---|---|---|
| doorway, window, arch | relief woodcut, linocut | carve, cut, cross |
| fog, soot, darkness | charcoal, graphite, frottage | rub, erase, lift |
| rain, puddle, wet stone | monotype, ink wash, transfer | bleed, develop, pool |
| hard sunlight, cast shadow | screenprint, photogram, cyanotype | expose, print, burn |
| painted/coated surface | reduction print, charcoal handoff | stop, register, continue |
| glass, reflection | monotype, offset print | mirror, slip, transfer |
| repeated movement | stamping, crayon trace | stamp, drag, trail |

## One-medium discipline

Select one primary process. Describe:

- substrate response;
- mark formation;
- edge behavior;
- pressure/exposure/ink variation;
- negative space;
- how the source trigger causes it.

Do not stack medium names to simulate originality.

## Intervention scale

- 5–15%: poetic discovery; usually weak for short-form social unless motion carries it.
- 20–40%: balanced editorial intervention.
- 40–70%: high-impact transformation; require a strong photographic anchor.
- over 70%: usually becomes style transfer; justify explicitly.

For Douyin-first work, default to 35–65% with one unmistakable preserved anchor.

## Source-specificity test

Ask: “Could the same prompt work unchanged on most photos in this category?” If yes, it is a filter. Rewrite the trigger, geometry, color source, contact zone, and action using actual observed facts.

## Novel mechanism

When no recipe fits, compile:

```text
Because [visible source fact] physically suggests [verb],
[exact photographic anchor] stays real while
[defined source region] becomes [single medium].
They meet at [existing contact zone], where [material interaction].
```
